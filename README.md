# 金融市場常識與職業道德｜線上練習

## 開始方式

- 本機開啟 `index.html`，或直接使用 [線上答題網站](https://df3011212.github.io/taiwan-financial-market-ethics-quiz/)。
- 選擇題庫範圍、每回題數、作答方式和題目順序。
- 「起始題序」可從指定位置分段練習。例如選金融市場常識、100 題、依題庫順序，輸入 101 即可練第 101–200 題；作答完成後可按「下一段」。
- 按「查看題庫」可依科目與題型分類瀏覽，支援每頁 25／50／100 題、跳頁與上一頁／下一頁；每題附正確答案。
- 題型分類包含否定辨識、市場區分、機關權責、金融商品、法規責任、客戶權益、招攬廣告及數字期限。題幹中的「不是／不屬／不得／正確」等判斷詞與數字會標示，並附上不改動官方答案的記憶提示。
- 練習時可按「上一題」回看；聽題模式也支援回播前一題。
- 聽題模式會朗讀題目和正確答案，接著自動播放下一題。可暫停、重播、手動跳題，並調整 0.7× 到 2× 語速。
- 頁面右上角可切換夜間／日間模式；選擇會保存在目前瀏覽器。
- 錯題、最佳成績和朗讀速度會保存在目前瀏覽器。

## 相似答案與相似題目追蹤

- 首頁新增「相似答案集」與「相似題目集」。已檢查 1,120 題，整理 116 組，涵蓋 301 個不重複題號：相似答案 55 組、相似題目 61 組。沒有相似對照依據的題目不強制入組。
- **相似答案**集中比較字樣、名稱或選項組合相近的題目。例如金融市場常識第 15、17、19、20 題都容易看混「XX 市場」；另有機關、基金、信託、保險、風險、保證金、縮寫、期限及相近句等群組。也收錄有具體意義的同答案組，並標明分組理由。
- **相似題目**比較同觀念或相近題幹，例如初級／次級市場、短期／中長期、正問／反問、相同情境換條件。整理為輔助分類，官方題目與答案維持不變。
- 作答區底部的「相似答案／相似題目」會在原題下方直接展開相關題幹與正確答案，不切換頁面；相關題目會去重並排除目前這題，可再點同一按鈕或「收起」關閉，作答與 PDF 位置保持不變。
- 每組可查看辨認線索、展開答案速覽、逐題對照；支援搜尋、考科與複習狀態篩選，以及「追蹤這一組」、「練習本組」、「只練待複習」與單題練習。
- 每題連續答對 2 次視為已熟悉，其餘列為待複習。記錄累計次數、答對率、錯誤次數、上次誤選與最近練習時間。一般練習確認答案或結束統計、測驗交卷時也會累計，同一次作答不重複計數；聽題不計入。
- 追蹤統計從新增功能後起算，不回推舊成績；原有錯題與成績儲存仍保留。測驗交卷前不開放答案集合對照。
- 可用題號自行建立分組，例如 `15,17,19,20` 或 `7-12`。追蹤紀錄與自訂分組儲存在此瀏覽器，可匯出 JSON 備份；匯入會合併追蹤組、保留同題較新的紀錄。
- 本機檔案與線上網站、不同瀏覽器各自保存進度；需要移轉時請匯出／匯入備份。

維護分組可執行 `python scripts/build_similarity_catalog.py`；只重建 `assets/similarity-data.js`，不改動官方題目。驗證追蹤與練習整合可執行 `node scripts/test-similarity-tracker.cjs` 及 `node scripts/test-similarity-integration.cjs`。
